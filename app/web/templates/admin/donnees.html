Le format
La première ligne nomme les colonnes, avec les noms de champ exacts, ceux de l'export.

Retrouver la ligne
Une colonne id désigne la ligne à modifier. Sans elle, la clé naturelle (Name, Address…) la retrouve. Une ligne inconnue est créée, si la table le permet.

Les règles
Celles des formulaires : seuls les champs manuels sont écrits, les options doivent exister, les liens doivent désigner une ligne existante. Une colonne absente n'est pas touchée, une cellule vide efface la valeur.

Le plus simple
Exporter, corriger dans le tableur, recoller. Les colonnes automatiques du fichier sont ignorées sans erreur.
